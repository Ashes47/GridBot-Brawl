GridBot Brawl – Game Guide

Overview

GridBot Brawl is a turn-based coding arena. Teams submit Python code that controls five bots, each with a unique role and special power. Matches run on a 10×10 grid (duo) or 15×15 grid (quad) and last up to 50 turns.

How to Play

  1. Write a single .py file that defines exactly five classes named Sniper, Tank, Bomber, Scout, and Teleporter. Each class must implement a decide(self, obs) method that returns an action dictionary.
  2. Go to Team Signup, enter team info, and upload your file.
  3. Wait for the orchestrator to schedule a match, or trigger one via the API.
  4. Watch replays in the Match Viewer and track your ranking on the Leaderboards.

Rules

  • All bots start with 100 HP.
  • Orthogonal movement only (N/E/S/W).
  • Bots see everything within 4-tile radius; visibility is shared team-wide.
  • Match ends when one team is eliminated or after 50 turns.
    – Tie-breakers: total team HP → surviving bots → draw.
  • Base attack deals 20 HP to an adjacent enemy tile.
  • No friendly fire except Bomber’s AoE (can hit allies).
  • Your decide method must finish within 100 ms and stay under 256 MB.

Example Strategy Snippets

Below are minimal ideas you can adapt:

  • Tank “Pusher” – move toward nearest enemy; shield when HP < 70.
  • Scout “Explorer” – dash east until wall, then south one tile, repeat (lawn-mower reveal).
  • Bomber “Kamikaze” – explode immediately if 2+ enemies adjacent, otherwise chase lowest-HP enemy.

You can browse existing teams on the Teams Directory to get inspiration—bot code itself is private, but match replays show behaviour.

Observation Object (per turn)

Your decide method receives a single argument obs – a plain Python dict with the following shape:

{
  "turn": 13,
  "map_size": [10, 10],
  "self": {
    "id": "alpha_3",
    "x": 4,
    "y": 3,
    "health": 60,
    "component": "sniper",
    "cooldowns": { "power": 0 }
  },
  "visible_enemies": [
    { "id": "beta_1", "x": 7, "y": 3, "team": "Beta", "component": "tank" },
    { "id": "beta_4", "x": 4, "y": 6, "team": "Beta", "component": "scout" }
  ],
  "visible_allies": [
    { "id": "alpha_1", "x": 3, "y": 3, "team": "Alpha", "component": "tank" },
    { "id": "alpha_2", "x": 5, "y": 3, "team": "Alpha", "component": "scout" }
  ]
}
  • turn: current turn number (0-based).
  • map_size: [width, height] – 10×10 or 15×15.
  • self: your bot’s current state including remaining power cooldown.
  • visible_enemies / visible_allies: bots within 4-tile radius (Chebyshev distance).

Writing Your Bot Classes

Create a file that defines exactly five classes – one per role. Each class must implement a decide(self, obs) method and may keep persistent state via instance attributes:

import random
from typing import Dict, Any

class Sniper:
    def __init__(self):
        # persisted across turns
        self.state: Dict[str, Any] = {"strafe": "east"}

    def decide(self, obs):
        # 1. Use observation to pick an action
        enemies = obs["visible_enemies"]
        me = obs["self"]

        # Snipe straight-line enemy ≤5 tiles
        for e in enemies:
            if e["x"] == me["x"] and abs(e["y"] - me["y"]) <= 5:
                return {"type": "snipe", "target": {"x": me["x"], "y": e["y"]}}
            if e["y"] == me["y"] and abs(e["x"] - me["x"]) <= 5:
                return {"type": "snipe", "target": {"x": e["x"], "y": me["y"]}}

        # 2. If no target: advance toward center of the map
        mid_x = obs["map_size"][0] // 2
        dir_ = "east" if me["x"] < mid_x else "west"
        return {"type": "move", "direction": dir_}

Repeat for Tank, Bomber, Scout, Teleporter.

Quick Tips

  • Store custom data in self.state (dict) to remember decisions.
  • Keep decide under 100 ms – avoid heavy computation.
  • Validate your output against the Action Dictionary.
  • The engine ignores unknown keys – be strict to avoid "idle" fallback.
