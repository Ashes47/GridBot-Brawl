Admin Console

Use your admin token for protected endpoints and the admin password for team-sensitive actions.

- Admin Token: Set header X-Admin-Token to access protected admin APIs (ratings, scheduler, baselines).
- Admin Password: Required for team-specific destructive actions (reset a team password, delete team).

Find Team: Loads all teams on page load. Use search to filter locally by team name. Click "Select" to target actions to that team.

Selected Team: None
Team status: valid = working code, invalid = broken code, testing = being tested, pending = not tested yet

    Leaderboard

    - Re-compute Ratings: Replay finished matches to rebuild rating history (non-destructive).
    - Re-evaluate (Reset): Clear matches/queue/ratings and re-enqueue calibration for all teams. Use with caution.

    Signup Settings

    Enable or disable public team signup. You can also bulk create teams from a CSV.

    Scheduler

    - Run Ongoing Scheduler: Schedules matches for teams per current policy.
    - Consume One Queue Cycle: Run one pass of the queue consumer to pop/advance jobs.
    - Calibrate Selected Team: Enqueue matchup calibration for the selected team.
    - Reset Selected Team: Clear its matches/ratings, delete logs, and recalibrate.

    Ratings & Baselines

    - Replay Ratings: Same as re-compute; triggers rating replay on background workers.
    - Inflate Sigma (Inactive): Increases uncertainty for inactive teams to let them move more on next results.
    - Leaderboard Rebuild: Rebuild leaderboard caches (safe).
    - Seed Baselines: Create/update pinned baseline teams and write their code files.

    Team Testing

    - Test All Teams: Test all teams against baselines to validate their code.
    - Team Status: View current validation status of all teams.
    - Test Selected Team: Test only the selected team against baselines.
